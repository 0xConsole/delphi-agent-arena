# SETUP — Delphi Agent Arena Operator Guide

Exact steps for an operator to go from zero to a running, trading agent on the
DoraHacks × Gensyn Delphi Agent Arena competition ($10K, deadline Aug 23 23:59 UTC).

The agent code is already built and tested. The only things that require a
human with a browser + wallet are: (1) registering your wallet, (2) funding it
with testnet ETH for gas, (3) getting the competition $TST tokens, and
(4) generating a Delphi API key via wallet signing. Once those four are done,
the agent runs autonomously.

---

## Prerequisites

- **Node.js 20+** and npm (`node --version`)
- **A browser** with an EVM wallet extension (MetaMask, Rabby, etc.)
- **A funded wallet** on Ethereum Mainnet or Sepolia (for the anti-bot faucet gate)
- The repo cloned:
  ```bash
  git clone https://github.com/0xConsole/delphi-agent-arena.git
  cd delphi-agent-arena
  npm install
  ```

---

## Step 1 — Register your wallet on DoraHacks

The competition uses **one wallet as your identity** — no code submission, no
GitHub repo required. Your registered wallet IS your entry.

1. Go to the hackathon page: **https://dorahacks.io/hackathon/delphi-agent-competition**
2. Click **Register** and connect your wallet (MetaMask/Rabby).
3. Complete the DoraHacks registration form.
4. Your wallet address is now your leaderboard identity.

> ⚠️ **One wallet per solo entrant or team.** Do not register multiple wallets.

---

## Step 2 — Get testnet ETH for gas

The agent needs ETH on the Gensyn Testnet (chain ID `685685`) to pay for gas on
every trade. The faucet is anti-bot gated — it requires **0.001 ETH on Ethereum
Mainnet** (burned as a sybil-resistance measure), OR you can bridge from Sepolia.

### Option A — Gensyn Testnet faucet (requires 0.001 ETH on Mainnet)

1. Go to the Gensyn Testnet faucet (linked from the competition app at
   https://competition.delphi.fyi/ — look for "Faucet" or "Get ETH").
2. Connect the same wallet you registered on DoraHacks.
3. The faucet will verify you hold ≥0.001 ETH on Ethereum Mainnet and dispense
   testnet ETH to your Gensyn Testnet address.
4. The faucet is **Cloudflare-protected** — this must be done in a browser,
   not via CLI.

### Option B — Bridge from Sepolia

1. Get Sepolia ETH from a public faucet (e.g. https://sepoliafaucet.com,
   https://www.alchemy.com/faucets/ethereum-sepolia).
2. Use the Gensyn bridge (linked from the competition app) to bridge Sepolia
   ETH → Gensyn Testnet ETH.

### Verify

```bash
# Add Gensyn Testnet to your wallet:
#   Network name: Gensyn Testnet
#   RPC: https://gensyn-testnet.g.alchemy.com/public
#   Chain ID: 685685
#   Currency: ETH
#   Explorer: (from competition app)
```

Check your balance in your wallet — you should see testnet ETH. The agent only
needs a small amount (~0.01 ETH is plenty for hundreds of trades).

---

## Step 3 — Get competition $TST tokens

Once your wallet is registered and allowlisted by Gensyn, it will be
**auto-funded** with an identical starting balance of competition $TST tokens
(6 decimals, contract `0x8A2d75753362Eb5D5669a2c22cbf394b26a0571F`).

1. Wait for the allowlist to process (Gensyn does this in batches after you
   register on DoraHacks — check the Delphi Discord for status).
2. Verify your $TST balance:
   - Add the token contract `0x8A2d75753362Eb5D5669a2c22cbf394b26a0571F` to your
     wallet as a custom ERC20 token on the Gensyn Testnet network.
   - You should see your starting balance.

> If you don't see tokens after 1+ hours, ask in the **Delphi Agent Arena**
> channel in the Delphi Discord (linked from the competition app).

---

## Step 4 — Generate the Delphi API key

The REST API (used for listing markets and positions) requires an API key,
generated by signing a message with your wallet.

1. Go to **https://delphi-api-access.gensyn.ai/**
2. Connect the same wallet you registered on DoraHacks.
3. Sign the authentication message when prompted (Privy-based wallet auth).
4. Copy the generated API key (it looks like a long string).

> This step **requires a browser with an injected EVM provider** (MetaMask/
> Rabby). It cannot be done from CLI — the signature needs the wallet's
> private key in a secure context.

## Step 5 — Configure the agent

```bash
cp .env.example .env
```

Edit `.env` and fill in these two values:

```bash
# Your wallet's private key (hex, with 0x prefix).
# Export from MetaMask: Account Details → Show Private Key.
# ⚠️  NEVER commit this file or share the key.
WALLET_PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE

# The API key from Step 4.
DELPHI_API_ACCESS_KEY=YOUR_API_KEY_HERE
```

All other values have sensible defaults. Optional tuning:

| Variable | Default | What it does |
|---|---|---|
| `DELPHI_NETWORK` | `competition-testnet` | The competition network |
| `AGENT_LOOP_INTERVAL_MS` | `300000` (5 min) | How often to scan + trade |
| `AGENT_MAX_RISK_PCT` | `3` | Max % of $TST balance per trade |
| `AGENT_MIN_EDGE` | `0.08` (8pp) | Min edge to act on |
| `AGENT_SLIPPAGE_PCT` | `2` | Buy slippage tolerance % |
| `AGENT_MAX_POSITIONS` | `12` | Max concurrent positions |
| `DASHBOARD_PORT` | `3001` | Local dashboard port |

## Step 6 — Verify the connection (smoke test)

```bash
npm run smoke
```

Expected output (with a funded wallet + API key):

```
[smoke] health: ok ✓
[smoke] wallet: 0xYOUR_ADDRESS
[smoke] ETH balance: 0.05
[smoke] $TST balance: 1000.00
[smoke] markets: 12 (open, with prices)
[smoke] positions: 0
[smoke] done — no trades placed.
```

If `health` is `ok` but `listMarkets` fails with "Requires apiKey", your
`DELPHI_API_ACCESS_KEY` is missing or invalid. If balances are 0, your wallet
isn't funded yet (Steps 2–3).

> The smoke test places **no trades** — it only reads state.

## Step 7 — Build

```bash
npm run build
```

This compiles the TypeScript to `dist/`. Should complete with zero errors.

## Step 8 — Run the agent

### Foreground (test / monitor)

```bash
npm start
```

This starts:
- The **trading loop** (scans markets → analyzes → buys → syncs → redeems, every 5 min)
- The **dashboard** on `http://localhost:3001` (balances, positions, P&L, trade log)

Watch the console output to see it scan markets, find signals, and execute
trades. The dashboard shows a live view at `http://localhost:3001`.

### Background (production — long-running)

Use `screen`, `tmux`, or a process manager (`pm2`, `systemd`) to keep the
agent running for the full competition window (now → Aug 23):

```bash
# Using tmux:
tmux new -s delphi
npm start
# Ctrl-B D to detach; tmux attach -t delphi to re-attach

# Using pm2 (if installed):
npm install -g pm2
pm2 start dist/index.js --name delphi-agent
pm2 logs delphi-agent
pm2 save && pm2 startup  # auto-restart on reboot
```

### Verify it's trading

After the first loop completes (~1 min), check:

1. **Console output** — look for `🔵 BUY` lines (executed trades) and
   `✓ tx=0x...` (transaction hashes).
2. **Dashboard** — `http://localhost:3001` shows positions + P&L.
3. **Competition leaderboard** — https://competition.delphi.fyi/ — your
   wallet should appear with trades/positions updating.

## Step 9 — Deploy the dashboard (optional, for a public URL)

The dashboard is also deployable to Vercel as a serverless function that reads
the persisted `data/portfolio.json`:

```bash
# Install Vercel CLI if needed:
npm install -g vercel

# Deploy:
vercel --prod
# (or with a token: VERCEL_TOKEN=xxx vercel --prod --yes --token "$VERCEL_TOKEN")
```

The dashboard at `https://delphi-agent-arena.vercel.app` shows the portfolio
state. Note: the serverless dashboard reads a **snapshot** of
`data/portfolio.json` — the live agent must be running on a long-lived host
(Step 8) and the portfolio file synced to the Vercel deployment for the
dashboard to show current data.

## Monitoring & troubleshooting

### The agent isn't trading

| Symptom | Cause | Fix |
|---|---|---|
| `no ETH for gas` | Wallet not funded (Step 2) | Get testnet ETH from faucet |
| `$TST balance: 0.00` | Wallet not allowlisted (Step 3) | Wait for Gensyn to fund, ask in Discord |
| `Requires apiKey` | API key missing/invalid (Step 4) | Regenerate at delphi-api-access.gensyn.ai |
| `signals: 0` | No markets with sufficient edge | Normal in quiet periods — agent waits |
| `buys executed: 0` | All signals filtered (dust guard, max positions) | Check `AGENT_MAX_RISK_PCT` and balance |
| `buy failed: ... revert` | Insufficient gas or token approval | Ensure ETH + re-run (agent auto-approves) |

### The agent stopped

The agent is designed to be safe to interrupt and restart — all state is
persisted to `data/portfolio.json`. Just restart it:

```bash
npm start
```

### Check P&L

```bash
# Via dashboard:
curl http://localhost:3001/api

# Or read the portfolio file directly:
cat data/portfolio.json | python3 -m json.tool | grep -E 'realizedPnl|loops|positions'
```

## Security notes

- **Never commit `.env`** — it contains your private key. It's in `.gitignore`.
- **Never share your private key** — it controls your wallet and competition entry.
- The `wallet.json` file in this repo (if present) is for development reference
  only — rotate the key before production use.
- The agent uses your private key **only** to sign on-chain transactions via
  the SDK — no third-party services receive it.
